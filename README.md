## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **CRT Shaders** | Recreate the authentic look of vintage monitors with scanline shaders |
| **Modern Features** | Mouse capture improvements, autotype, configurable blitter, and more |
| **Accurate Emulation** | Faithful CPU, Sound Blaster, AdLib, and MT-32 emulation |
| **Active Development** | Regular updates fixing bugs and adding features the original never had |
